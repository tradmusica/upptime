# Agent Instructions

> **Required first step:** Before starting any task in this repository, always first read the [organisation knowledge base](https://github.com/tradmusica/organisation). Start with its README and the documentation relevant to the task, then read this repository's instructions and documentation.

## Repository language

- Write repository-owned documentation, AGENTS instructions, descriptions, comments, commit messages and pull-request text in English.
- Preserve proper names, technical identifiers, paths, API values and original source evidence. User-facing correspondence follows the requested language.

## Commit message standard

- All commit messages must follow [Conventional Commits](https://www.conventionalcommits.org/).
- Use `<type>(<scope>): <summary>`; the scope is optional. Keep each commit focused on one logical purpose and use a concise, concrete summary.
- Mark breaking changes with `!` before the colon or a `BREAKING CHANGE:` footer.
- Existing repository-specific commit authorization and branch-protection rules remain in effect. This message-style requirement does not grant permission to commit.
